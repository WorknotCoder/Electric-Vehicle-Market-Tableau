# Electric Vehicle Market Performance & Insights Dashboard

An interactive Tableau data visualization project analyzing global electric vehicle (EV) market trends, adoption rates, vehicle specifications, and market dynamics. 

---

## 📌 Project Overview
This project provides an end-to-end analysis of the Electric Vehicle market. Using Tableau, it transforms complex dataset metrics into clear visual insights to help stakeholders understand EV adoption patterns, battery technology advancements, manufacturer market shares, and pricing trends.

---

## 🎯 Key Features & Insights
- **Market Share & Adoption:** Breakdown of BEV (Battery Electric Vehicles) vs. PHEV (Plug-in Hybrid Electric Vehicles) adoption over time.
- **Geographic Distribution:** Interactive map highlighting EV registration density by region/state.
- **Manufacturer Performance:** Top-performing EV makes and models ranked by sales volume and average market price.
- **Technical Metrics:** Analysis of average electric range (miles/km) relative to MSRP and model year improvements.
- **CAFV Eligibility:** Tracking Clean Alternative Fuel Vehicle (CAFV) incentive eligibility trends across registered models.
